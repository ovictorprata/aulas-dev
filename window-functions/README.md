# Aula: Window Functions (SQL)

Aula de 1h30 sobre window functions, usando a Retrospectiva do Spotify como exemplo.

| Pasta | Conteúdo |
| --- | --- |
| `material/` | Material interativo em React (Vite + TypeScript): explicação passo a passo, editor de SQL no navegador e lista de exercícios com correção automática |
| `sql/` | Scripts para o MySQL Workbench: `spotify.sql` (banco da aula) e `loja.sql` (banco da lista extra) |
| `slides/` | Código-fonte dos slides (um HTML por slide + `deck.css` e `deck.json`) |

## Rodar o material

```bash
cd material
npm install
npm run dev
```
