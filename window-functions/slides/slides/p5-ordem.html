O MySQL não lê na ordem em que escrevemos

1º

FROM

pega a tabela

2º

WHERE

filtra as linhas

3º

SELECT

calcula as colunas

window function

4º

ORDER BY

ordena o resultado

A window function só é calculada no 3º passo. O WHERE roda no 2º, antes dela existir.

Um clique por etapa. A gente escreve SELECT primeiro, mas o MySQL executa o FROM primeiro e o WHERE antes do SELECT. A window function é calculada junto com as colunas do SELECT, no 3º passo. Por isso o WHERE, no 2º, ainda não conhece a coluna posicao. Analogia: é como filtrar as notas de uma prova que ainda não foi corrigida. Por isso ela pode aparecer no ORDER BY, que vem depois, mas não no WHERE.
