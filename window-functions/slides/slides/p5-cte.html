Solução: primeiro calcula, depois filtra

WITH ranking AS (

SELECT usuario, musica, plays,

RANK() OVER (PARTITION BY usuario ORDER BY plays DESC) AS posicao

FROM mais_ouvidas

)

SELECT * FROM ranking

WHERE posicao <= 3;

1. O WITH calcula a consulta e dá um nome para ela: ranking.

2. Depois, o SELECT de fora usa o ranking como se fosse uma tabela e filtra.

O WITH é como salvar um resultado num rascunho com nome para usar depois. Primeiro mostre só a parte de dentro, que é a consulta do passo 4. Clique: aparece o SELECT de fora, que filtra o rascunho.
