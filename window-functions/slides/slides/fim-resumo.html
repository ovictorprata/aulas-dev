Toda window function, em uma linha

RANK() OVER (PARTITION BY usuario ORDER BY plays DESC)

RANK()

Qual conta?

PARTITION BY

Em quais grupos?

ORDER BY

Em qual ordem?

Toda window function responde a essas três perguntas. O PARTITION BY e o ORDER BY são opcionais: sem PARTITION BY, a tabela inteira é um grupo só; sem ORDER BY, a conta usa o grupo todo, como no SUM.
